### โครง web 3 พื้นที่ (`central/src/school/UnifiedShell.tsx`)

| พื้นที่ | ใครเห็น | path |
|---|---|---|
| ① ระบบงานโรงเรียน | ทุกคน (ตามฝ่ายที่ได้สิทธิ์) | `/school`, `/school/division/...`, `/public/:schoolId` |
| ② ตั้งค่าโรงเรียน | แอดมินโรงเรียน + ส่วนกลาง | `/school/settings/*` (ทั่วไป, ฝ่ายและบุคลากร, สิทธิ์การใช้งาน, LINE, ลงเวลา, แบบฟอร์ม) · `/school/division/hr/departments-staff` (สถานะบุคลากร, ตำแหน่งบริหาร) |
| ③ ศูนย์ส่วนกลาง | ส่วนกลางเท่านั้น | `/admin`, `/admin/schools`, `/admin/admins`, `/admin/role-permissions`, `/admin/forms`, `/admin/line` (คง redirect จาก path เดิมไว้ครบ) |

- ตัวเลือกโรงเรียนมีเฉพาะใน ③ หน้าอื่นรับ `lockedSchoolId` / `fixedScope`
- path เดิมคงไว้ เพราะ app ลิงก์ตรงมาที่ `admin/mapping`, `admin/division-permissions`, `user-permissions`, `division/hr/appointment-orders`
- ส่วนกลางล็อกอินแล้วไป `/hq` อัตโนมัติ (ยกเว้นเปิดจากในแอปวันลา)

## ข้อจำกัดที่รู้อยู่

- ปุ่ม "ทดลองส่ง" LINE / สรุปลงเวลา ยังใช้ได้เฉพาะส่วนกลาง (ตรวจใน Edge Function)
- สะพานเชื่อม LINE กลาง (`Settings.webhookUrl`) อยู่ที่ `/hq/line` ใช้ร่วมทุกโรงเรียน
- ถ้ารัน `attendance_permissions.sql` / `official_trips_permissions.sql` ซ้ำ กฎ `Permissions_menu_id_range` จะกลับเป็น 0–10 → ต้องรัน `school_web_division_edit.sql` ซ้ำ
- ลำดับตัดสินสิทธิ์อยู่ 2 ที่: web (`resolveDivisionAccess` / `resolveModuleAccess` ใน `staffDivisionMapping.ts`) และฐานข้อมูล (`can_edit_school_web`) แก้ที่หนึ่งต้องแก้อีกที่ให้ตรงกัน
- ถ้าส่วนกลางปิดระบบงาน `public-web-settings` ในแพ็กเกจ ฐานข้อมูลยังไม่เช็กเพดานแพ็กเกจ (ครูที่ได้สิทธิ์ยังบันทึกได้)
- เว็บสาธารณะแสดงรายชื่อ / รูปครูทุกคนของโรงเรียนอัตโนมัติ (`get_public_school_realtime_data`) โรงเรียนยังเลือกปิดไม่ได้
- SQL ใหม่ทุกไฟล์จบด้วย `insert into "SchemaMigrations"(name) ...` (ดู README)
