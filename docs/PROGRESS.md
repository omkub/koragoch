## กติกาที่ต้องถือ

- **ระบบวันลา (app, `lib/`) ห้ามแก้** งานทั้งหมดแก้เฉพาะ web (`central/`) และ SQL ที่ไม่กระทบ app
- คำเรียกส่วนต่างๆ ดู `CLAUDE.md`
- เจ้าของ merge PR เอง และรัน SQL เอง (ลำดับรันอยู่ใน `README.md`)

## คำตอบเจ้าของระบบ (ใช้เป็นหลักออกแบบ)

1. ไม่มีเว็บสาธารณะของโรงเรียน
2. แอดมินโรงเรียนจัดการได้เฉพาะโรงเรียนตัวเอง
3. ระบบวันลาเป็นระบบย่อยของโรงเรียน ครูต้องได้รับสิทธิ์ฝ่ายจากแอดมินโรงเรียนก่อนจึงเข้าเว็บโรงเรียนได้
4. ครูใช้ได้ทั้ง PC และมือถือ
5. ผู้ดูแลส่วนกลางตอนนี้มี 1 คน ดูทุกโรงเรียน ส่วนแอดมินโรงเรียนคือบุคลากรของโรงเรียนนั้น

### โครง web 3 พื้นที่ (`central/src/school/UnifiedShell.tsx`)

| พื้นที่ | ใครเห็น | path |
|---|---|---|
| ① ระบบงานโรงเรียน | ทุกคน (ตามฝ่ายที่ได้สิทธิ์) | `/`, `/division/...` |
| ② ตั้งค่าโรงเรียน | แอดมินโรงเรียน + ส่วนกลาง | `/admin/*`, `/user-permissions`, `/settings`, `/staff`, `/admin-positions`, `/forms`, `/line`, `/attendance` |
| ③ ศูนย์ส่วนกลาง | ส่วนกลางเท่านั้น | `/hq`, `/hq/forms`, `/hq/line`, `/schools`, `/admins`, `/role-permissions` |

- ตัวเลือกโรงเรียนมีเฉพาะใน ③ หน้าอื่นรับ `lockedSchoolId` / `fixedScope`
- path เดิมคงไว้ เพราะ app ลิงก์ตรงมาที่ `admin/mapping`, `admin/division-permissions`, `user-permissions`, `division/hr/appointment-orders`
- ส่วนกลางล็อกอินแล้วไป `/hq` อัตโนมัติ (ยกเว้นเปิดจากในแอปวันลา)

## ข้อจำกัดที่รู้อยู่

- ปุ่ม "ทดลองส่ง" LINE / สรุปลงเวลา ยังใช้ได้เฉพาะส่วนกลาง (ตรวจใน Edge Function)
- สะพานเชื่อม LINE กลาง (`Settings.webhookUrl`) อยู่ที่ `/hq/line` ใช้ร่วมทุกโรงเรียน
