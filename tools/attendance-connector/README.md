# ตัวเชื่อมเครื่องสแกนหน้า (พาร์ท 7)

ส่งเวลาสแกนจากคอมพิวเตอร์ที่โรงเรียนเข้าระบบลงเวลาอัตโนมัติ

## ต้องใช้ไหม

| เครื่องสแกนของโรงเรียน | วิธีเชื่อม |
|---|---|
| ส่งข้อมูลออกทางอินเทอร์เน็ตเองได้ (HTTP push / webhook) และตั้ง URL กับ header เองได้ | **ไม่ต้องใช้ตัวนี้** ตั้งให้เครื่องส่งตรงเข้า `attendance-ingest` (ดู `supabase/functions/README.md`) |
| export ไฟล์ได้ หรือมีโปรแกรมของยี่ห้อที่ดึงข้อมูลมาเก็บเป็นไฟล์บนคอม | **ใช้ตัวนี้** |
| ยังไม่มีอะไรเลย | ระหว่างนี้แอดมินนำเข้าไฟล์เองได้ที่ app > จัดการระบบ > นำเข้าเวลาสแกน |

ตัวเชื่อมนี้ยังไม่ได้ทดสอบกับเครื่องจริง ทดสอบแล้วเฉพาะกับไฟล์ตัวอย่างแบบ ZKTeco `attlog.dat`, CSV และ TXT
เมื่อได้เครื่องแล้วให้ทำขั้นที่ 3 (`-DryRun`) ก่อนเสมอ ถ้าอ่านไม่ถูก ส่งไฟล์ตัวอย่างจากเครื่องมาให้ปรับได้

## ติดตั้ง (Windows ไม่ต้องลงโปรแกรมเพิ่ม)

1. คัดลอกโฟลเดอร์นี้ไปไว้ที่คอมที่โรงเรียน เช่น `C:\AttendanceConnector`
2. ที่ web > ลงเวลา > เครื่องสแกน กด "ลงทะเบียนเครื่อง" แล้วคัดลอก **รหัสลับเครื่อง**
3. คัดลอก `config.example.json` เป็น `config.json` แล้วแก้ค่า:

   | ค่า | ความหมาย |
   |---|---|
   | `deviceKey` | รหัสลับเครื่องจากข้อ 2 |
   | `folder` | โฟลเดอร์ที่โปรแกรมของเครื่องสแกน export ไฟล์ไว้ (ใช้ `\\` หรือ `/` คั่น) |
   | `filePattern` | เว้นว่าง = อ่าน `*.csv *.txt *.dat *.tsv` / หรือระบุ เช่น `attlog*.dat` |
   | `dateOrder` | วันที่แบบ `09/10/2026`: `DMY` = 9 ต.ค. (ค่าเริ่มต้น), `MDY` = 10 ก.ย. — แบบ `2026-10-09` ไม่ต้องตั้ง |
   | `codeColumn` | `0` = เดาเอง (ช่องตัวเลขแรกก่อนวันเวลา) / หรือระบุลำดับคอลัมน์ของรหัสพนักงาน เริ่มที่ 1 |
   | `recurse` | `true` = อ่านโฟลเดอร์ย่อยด้วย |

4. ทดสอบ (เปิด PowerShell ในโฟลเดอร์นี้):

   ```
   powershell -ExecutionPolicy Bypass -File attendance-connector.ps1 -Test
   powershell -ExecutionPolicy Bypass -File attendance-connector.ps1 -DryRun
   ```

   - `-Test` ต้องได้ "เชื่อมต่อสำเร็จ"
   - `-DryRun` ต้องเห็นรหัสกับเวลาตรงกับในเครื่อง (ยังไม่ส่งข้อมูล)

5. ตั้งให้รันเองทุก 5 นาที — เปิด Command Prompt แบบ Administrator:

   ```
   schtasks /Create /TN "AttendanceConnector" /SC MINUTE /MO 5 /RU SYSTEM /TR "powershell -NoProfile -ExecutionPolicy Bypass -File C:\AttendanceConnector\attendance-connector.ps1"
   ```

   ยกเลิก: `schtasks /Delete /TN "AttendanceConnector" /F`

## ทำงานอย่างไร

- ส่งเฉพาะบรรทัดใหม่ของแต่ละไฟล์ จำไว้ใน `state.json`
  - ไฟล์ถูก export ใหม่ทั้งไฟล์ (สั้นลง) = อ่านใหม่ทั้งไฟล์
  - ส่งซ้ำก็ไม่เบิ้ล ฐานข้อมูลกันซ้ำให้
- ส่งไม่สำเร็จ (เน็ตล่ม) = ไม่บันทึก `state.json` รอบหน้าส่งใหม่เอง
- บันทึกการทำงานใน `connector.log`
- ส่งทั้งหมดใหม่: เพิ่ม `-ResendAll`
- รหัสที่ยังไม่ได้จับคู่กับครูถูกเก็บไว้ก่อน ใส่รหัสให้ครูที่ web แล้วระบบผูกให้เอง

## ความปลอดภัย

- `config.json` มีรหัสลับเครื่อง ห้ามส่งต่อหรือ commit เข้า git (มี `.gitignore` กันไว้แล้ว)
- รหัสหลุด: ที่ web กด "ออกรหัสใหม่" แล้วแก้ `config.json` รหัสเดิมจะใช้ไม่ได้ทันที
- ไฟล์ export มีแค่รหัสกับเวลา ไม่มีภาพใบหน้า
